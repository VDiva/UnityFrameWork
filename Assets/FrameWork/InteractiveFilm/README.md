# 影游编辑器

通过 **FrameWork → 影游 → 影游编辑器** 打开可视化剧情图，双击剧情资产也可以打开。通过 **新建剧情图** 创建一个带双结局的模板。

## 连线和视频

1. 在画布空白处按 Space，添加入口、视频片段、选项分支或结局。
2. 将上一个节点的输出连到下一个节点的「进入」端口。每个选项有独立输出，多个分支可以汇合到同一个节点。
3. 在视频片段节点设置 Video、封面、字幕和 Auto Advance。绑定 VideoClip 后可播放，勾选 Auto Advance 会在视频结束后进入下一段。空视频节点显示文字和继续按钮，可先用来搭剧情。
4. 在选择节点点击 **+ 添加选项** 增加任意数量的选项。每行生成对应编号的输出端口，把它连接到对应剧情即可。删除选项只会移除该选项的连线，操作可撤销。完成后点击 **检查连线** 和 **保存**。运行时选项过多会出现滚动列表。

## 场景和运行

从 **FrameWork → 影游 → 打开雾港示例** 打开演示场景，进入 Play Mode 后体验两个结局。示例使用文字占位，导入你自己的视频即可替换。

接入其他场景时，添加 `FilmPlayer` 并绑定剧情图。默认播放器会显示视频、字幕和选项。关闭 Show Built In Ui 后，可自己做界面并使用 `NodeChanged`、`VideoTexture`、`Advance()`、`Choose(index)` 和 `Restart()`。选项索引从 0 开始。
