# 影游编辑器

在 Unity 中用节点和连线制作交互式视频剧情。剧情保存在 `FilmGraph` 资产中，可由不同场景中的播放器复用。

## 快速开始

1. 在 Unity 菜单中选择 **FrameWork → 影游 → 新建剧情图**，保存一个带双结局的模板。双击已有剧情资产也可以打开编辑器。
2. 在画布空白处按 **Space** 添加节点。将上一个节点的输出拖到下一个节点的 **进入** 端口。多条分支可以汇合到同一个节点。
3. 点击 **检查连线**，修复缺失的出口、选项文字或无法从入口到达的节点，然后点击 **保存**。

## 节点与选项

| 节点 | 用法 |
| --- | --- |
| 入口 | 每张剧情图有一个入口，连接到第一段剧情。 |
| 视频片段 | 可配置标题、封面、字幕和 `VideoClip`。开启 **Auto Advance** 后，视频播完会自动进入下一段。未绑定视频时，可用文字和 **继续** 按钮先跑通剧情。 |
| 选项分支 | 点击 **＋ 添加选项** 增加任意数量的选项。每行对应同编号的输出端口，填写文字后连接目标节点。 |
| 结局 | 显示结局文字，并提供 **重新开始**。 |

删除选项时，只会移除该选项及其连线，可以撤销。播放时，如果选项超出显示区域，玩家可以滚动查看。旧版固定三个端口的剧情会自动迁移，已有选项和连线会保留。打开旧图后点击 **保存**，即可写入新格式。

## 播放示例和接入项目

选择 **FrameWork → 影游 → 打开雾港示例**，进入 Play Mode。点击 **继续** 后，分别选择「呼叫救援队」或「联系灯塔管理员」可体验两个结局。示例使用文字占位，可将自己的视频拖到片段节点的 **Video** 字段。

接入其他场景时，在 GameObject 上添加 `FilmPlayer`，将剧情资产拖入 **Graph** 字段。默认界面会显示视频、字幕和选项，也可通过 **UI Font** 指定自己的字体。使用自定义界面时，关闭 **Show Built In Ui**，再通过以下接口驱动播放。

| 接口 | 用途 |
| --- | --- |
| `NodeChanged` / `CurrentNode` | 监听剧情切换或读取当前节点。 |
| `VideoTexture` / `PlaybackError` | 获取当前视频画面或播放错误。视频尚未准备好时，纹理为空。 |
| `Advance()` | 从当前视频片段进入下一节点。 |
| `Choose(index)` | 选择当前分支的选项。索引从 0 开始，对应界面上的选项 1。 |
| `Restart()` | 从剧情入口重新开始。 |
